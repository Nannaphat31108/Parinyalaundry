# Parinya Laundry — ระบบ POS ร้านซักรีด

เว็บแอป (PWA) ใช้งานบนมือถือ/แท็บเล็ต/คอมได้ ข้อมูลเก็บในเครื่อง (localStorage) และเชื่อมหลายเครื่องผ่าน Firebase ได้

- รับผ้า / คิดเงิน, ลูกค้า, แพ็คเกจ, ใบเสร็จ, บัญชีรายรับรายจ่าย, เครื่องพิมพ์ใบเสร็จ
- โทนสีฟ้า-ขาว

## รันในเครื่อง

```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

เป็นไฟล์ static ทั้งหมด นำขึ้น GitHub Pages / Render / Netlify ได้ทันที
